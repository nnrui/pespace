**pespace**: 
====================================================================================
-----------------------------------------------------------------------
A parameter estimation tool for space-borne gravitaional wave detectors
-----------------------------------------------------------------------

.. toctree::
   :maxdepth: 2
   :caption: Contents:

Key features:
=============

- GPU accelerated response generation and likelihood evaluation (based on the ``taichi-lang``).
- Common frequency domain likelihood for Gaussian stationary noise.
- wavelet domain likelihood.
- Fisher information matrix likelihood (based on the autodiff system in ``taichi-lang``).
